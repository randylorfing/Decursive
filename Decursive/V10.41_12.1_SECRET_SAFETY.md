# v10.41 — WoW Retail 12.1 secret-aura safety pass

This build standardizes Decursive's 12.1 runtime on Blizzard-managed aura filtering.

## Runtime policy

- Real dispel detection on Retail 12.1 is performed by `AuraContainer` / `AuraButton`.
- Legacy Lua aura enumeration is not used on 12.1, including Open World.
- Environment profiles still control reaction, range, cooldown, priority, and presentation behavior; they no longer switch the underlying aura-detection engine.
- Direct aura-detail compatibility helpers return no aura data on 12.1; managed frames own that state.

## Secret-value handling

- Unit identity/possession wrappers call the Blizzard API and validate each returned value with `canaccessvalue()` before using it.
- This avoids unnecessarily dropping readable unit information solely because `InCombatLockdown()` is true.

## Additional fix

Two MUF class-color paths now correctly capture the second return value from `UnitClass()` / `GetUnitClassSafe()`.
