# Zhaohu's Decursive for World of Warcraft Retail

Zhaohu's Decursive is a dispel assistant for World of Warcraft Retail 12.1. It
preserves Decursive's compact secure Micro Unit Frames (MUFs) and click-to-cure
workflow while adding a modern settings interface, Blizzard-native
protected-aura support, alerts, profiles, and cooldown feedback.

Open settings with `/dcr`, `/decursive`, `/zd`, or `/zdecursive`. The same
window is available through Blizzard Settings and the addon's options keybind.

## What it provides

- Automatic cure-spell detection for the current class, specialization, and talents
- Secure click-to-cure MUFs for party and raid members
- Configurable cure priorities and mouse or modifier bindings
- Priority and Skip Lists
- Optional text, sound, range, and cooldown feedback
- Automatic Open World, Dungeon, Mythic+, Raid, and PvP environment profiles
- Blizzard-managed protected-aura presentation on WoW 12.1
- A LoadOnDemand `Decursive_Options` companion with the complete settings catalog

Install both `Decursive` and `Decursive_Options` from the same packaged
release. Do not install GitHub's automatic source archive, because it has not
been processed by the addon packager.
