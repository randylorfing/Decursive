# Zhaohu's Decursive v12.0.1

The live **DISPEL alert warning** is now enabled by default.

- New profiles start with the warning enabled.
- Existing profiles that never explicitly changed the setting inherit the new enabled default.
- An existing explicit disabled choice is preserved.
- Timed mode still defaults to 2 seconds and remains adjustable in the options.

PvP environment profiles now disable all Decursive center-screen alert text by default:

- DISPEL and Soul Link text are suppressed while the PvP profile is active.
- Sound notifications and MUF indicators remain available.
- The new **PvP on-screen text alerts** switch in **Profiles & Modes** can opt back in.
- Existing profiles receive this PvP-off behavior once; subsequent user choices are preserved.
- Options-panel alert previews continue to work even when the PvP live-text switch is off.

This release contains no change to protected-aura detection, native sound playback, secure click casting, or the v11.1.4 font-size correction.
